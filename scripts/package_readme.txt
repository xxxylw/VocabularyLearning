VocabularyLearning v{VERSION} — Windows 本地单机版
================================================

快速开始
--------
1. 解压本压缩包到任意文件夹（建议非系统盘，如 D:\VocabularyLearning）。
2. 双击 VocabularyLearning.exe。
3. 等待几秒，浏览器会自动打开学习界面（http://127.0.0.1:8000/），
   默认单词书为「雅思词汇真经」（3,383 词）。

日常使用
--------
- 程序启动后在系统托盘（右下角，可能收在 ^ 折叠区）常驻图标。
- 关闭浏览器标签页不会退出程序，学习进度已实时保存；
  双击托盘图标或右键菜单选 Open Study 可重新打开学习界面。
- 退出程序：右键托盘图标 → Exit。请勿长期用任务管理器结束进程
  （异常退出不丢已保存进度，但建议走 Exit）。

数据保存在哪里？
----------------
你的学习进度、复习记录和设置保存在：
    %APPDATA%\VocabularyLearning\
（即 C:\Users\<你的用户名>\AppData\Roaming\VocabularyLearning）

- 删除、移动或重新解压本程序文件夹不会影响你的学习进度。
- 升级新版本：下载新 zip，解压覆盖即可；用户数据目录不受影响。
- 想彻底重置进度：退出程序后删除上述文件夹即可（下次启动会
  重新复制内置词库）。

联网说明
--------
核心学习流程（Today study、复习调度、拼写练习）完全离线可用，
无需注册账号。
默认不联网查询 Oxford/Wiktionary。如需启用在线增强查询，在
%APPDATA%\VocabularyLearning\ 下新建 settings.json，内容为：
    {"online_enrichment": true}
重启程序后生效；离线时按既有降级口径展示，不报错。

Windows SmartScreen 提示
------------------------
首次运行可能弹出「Windows 已保护你的电脑」。原因：本程序未购买
代码签名证书。处理：点击「更多信息」→「仍要运行」。

端口说明
--------
默认使用 8000 端口；被占用时会自动改用其他可用端口，
浏览器仍会打开正确地址。

问题排查
--------
- 日志位置：%APPDATA%\VocabularyLearning\logs\launcher.log
- 界面打不开：检查托盘图标是否仍在；杀毒软件拦截时请放行本程序。
