# VocabularyLearning v1.0.0

首个正式发布：Windows 本地单机版（绿色压缩包）。

## 新特性

- Windows 绿色包：解压即用，无需安装 Python / Node / pnpm，双击 `VocabularyLearning.exe` 即可学习。
- 无控制台黑窗；系统托盘常驻，托盘菜单提供 **Open Study**（重新打开学习界面）与 **Exit**（退出）。
- 内置「雅思词汇真经」单词书全量数据（3,383 词，含释义、例句、学习卡片与已缓存音标），首次启动自动复制到用户数据目录。
- 学习进度、复习记录与设置保存在 `%APPDATA%\VocabularyLearning\`，按 Windows 账户天然隔离，互不覆盖。
- 自适应间隔重复复习调度（简化 SM-2）、Today study、拼写练习全部本地可用。
- 默认端口（8000）被占用时自动改用可用端口。
- 单实例：重复双击启动器不会启动第二份服务，只会唤起学习界面。
- Oxford / Wiktionary 在线查询为可选联网增强（默认关闭，见包内 README.txt），核心学习流程完全离线。

## 修复

- 升级 / 重新解压 / 移动应用目录不影响用户学习进度（用户数据与应用目录彻底分离）。
- 异常退出（断电、任务管理器结束进程）后重启，已保存的学习进度完好。

## 已知问题

- 未购买代码签名证书，首次运行会触发 Windows SmartScreen「已保护你的电脑」提示，选择「更多信息 → 仍要运行」即可（详见下方安装步骤）。
- 无自动更新：新版本需手动下载新 zip 解压覆盖（用户数据不受影响）。
- 部分杀毒软件可能对未签名的 PyInstaller 程序误报，需手动放行。
- 在线查询（Oxford / Wiktionary）默认关闭；启用后断网时按降级口径展示，不影响核心流程。

## 安装与使用

1. 下载 `VocabularyLearning-v1.0.0-win64.zip` 并解压到任意文件夹（建议如 `D:\VocabularyLearning`）。
2. 如出现 SmartScreen 提示：点击「更多信息」→「仍要运行」（原因：程序未购买代码签名证书，属正常现象）。
3. 双击 `VocabularyLearning.exe`，等待数秒后浏览器自动打开学习界面（`http://127.0.0.1:8000/`）。
4. 学习。关闭浏览器标签页不会退出程序；退出请用托盘图标右键 → **Exit**。

## 退出步骤

- 正常退出：系统托盘（右下角）右键 VocabularyLearning 图标 → **Exit**。
- 验证退出成功：任务管理器中不再有 `VocabularyLearning.exe` 进程。

## 数据目录说明

- 学习进度、复习记录、设置与日志位于 `%APPDATA%\VocabularyLearning\`（资源管理器地址栏粘贴该路径即可打开）。
- 删除或移动应用文件夹不影响学习进度；删除上述数据目录即彻底重置。
